# SHS Sommar Hockey Skolan 2026

Planeringen för Team-16 verksamheten under Sommarhockeyskolan 2026.

Se materialet renderat på https://willeeklund.github.io/shs26/

Källkoden för allt detta finns publikt [här på Github](https://github.com/willeeklund/shs26).


## Tankar vid skapandet av materialet
Grundtanken: vi jobbar tillsammans för att **diskutera, upptäcka och lära** - vi ska inte bara lyssna på teori. Målgruppen är 10-åriga hockeyspelare, så varje workshop är byggd för att vara **kort, lekfull och interaktiv**.

Materialet är baserat på kurserna som ges av Svenska ishockeyförbundet, men omarbetat för att 10 åringar ska kunna ta till sig det.
