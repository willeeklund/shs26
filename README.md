# SHS Sommar Hockey Skolan 2026

Planeringen för Team-16 verksamheten under Sommarhockeyskolan 2026.

👉 **[Öppna workshop-sidan](https://willeeklund.github.io/shs26/)** - en enda länk, inget mer behövs. Klicka på en workshop för att öppna presentationen direkt i webbläsaren.

## Varför ser det ut så här?
Grundtanken: vi jobbar tillsammans för att **upptäcka och lära** - vi ska inte bara lyssna på teori. Målgruppen är 10-åriga hockeyspelare, så varje workshop är byggd för att vara **kort, lekfull och interaktiv** - inte en lärare som pratar i 30 minuter. Konkret betyder det:
- Max en fråga eller idé per bild, stora bokstäver och gott om emoji 🏒🔥🙌
- Spelarna jobbar själva i smågrupper med riktiga situationer - både på isen och utanför
- De ritar egna lösningar på isbane-diagram istället för att bara bli tillsagda
- QR-koder till filmklipp så de kan kolla om och om igen på sin egen platta/telefon
- Varje presentation går snabbt att klicka igenom tillsammans med hela laget

Tanken är att workshoparna ska kännas som ett kul avbrott i vardagen - inte som skolan.
